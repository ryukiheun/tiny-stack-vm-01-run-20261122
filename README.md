A tiny stack VM for make.fun's own ISA: runs each `program.bin` on its `input.bin` and answers with the bytes it writes and its exit code. 32-bit wrapping arithmetic, 256-slot stack, calls, 256 memory words, all ten traps with their own codes, step and output limits. MIT — see [LICENSE](LICENSE).

```sh
node main.ts # /input/<id>/ -> /output/<id>/stdout.bin + exit.txt
```
